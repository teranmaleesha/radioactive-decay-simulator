# ⚛️ Radioactive Decay & Isotope Half-Life Simulation Dashboard

An interactive scientific dashboard built with **Python**, **Streamlit**, and **Matplotlib** to simulate and visualize radioactive decay kinetics across various isotopes. Designed to aid educational research and demonstrate applied scientific programming for academic portfolios.

---

## 🚀 Features
- **Interactive Isotope Selection:** Pre-configured with standard half-lives for *Carbon-14*, *Uranium-235*, and *Cobalt-60*, plus custom half-life inputs.
- **Dynamic Decay Modeling:** Real-time mathematical simulation of exponential radioactive decay curves ($N(t) = N_0 e^{-\lambda t}$).
- **Customizable Parameters:** Adjust initial atom counts ($N_0$) and time multipliers dynamically via sidebar controls.
- **Data Analytics Panel:** Instant summary statistics tracking remaining atomic concentrations.

---

## 🛠️ Tech Stack
- **Python** (Core Logic & Scientific Calculations)
- **Streamlit** (Interactive Web App Framework)
- **NumPy** (Numerical Array Computations)
- **Matplotlib** (Data Visualization & Plotting)
